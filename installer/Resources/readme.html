Zanim zainstalujesz

  • Format: VST3 (macOS, Apple Silicon / arm64).
  • Kompatybilne programy: Reaper, FL Studio (macOS) oraz każdy inny host obsługujący VST3.
  • Ten pakiet nie jest podpisany certyfikatem Apple Developer ID. Jeśli system pokaże ostrzeżenie o nieznanym deweloperze, kliknij pakiet prawym przyciskiem myszy → Otwórz, albo zezwól na instalację w Ustawienia systemowe → Prywatność i bezpieczeństwo.
  • Instalacja "dla wszystkich użytkowników" poprosi o autoryzację (Touch ID lub hasło administratora) — to standardowe zachowanie instalatora macOS przy zapisie do systemowego folderu wtyczek.
